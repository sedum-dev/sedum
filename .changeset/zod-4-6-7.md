Update zod from 4.6.5 to 4.6.7. Zod before 4.6.6 can exhaust memory while validating oversized constrained collections ([GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)), so a fresh `npm install -D sedum-cli` reported 6 high-severity vulnerabilities in `npm audit`. It now reports none.
