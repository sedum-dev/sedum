# Security policy

Please do not disclose a vulnerability in a public issue. Use GitHub's private vulnerability reporting for the `sedum-dev/sedum` repository, or contact the maintainers privately through the repository's security contact if that feature is unavailable. Include reproduction steps and the affected version. Do not include live credentials or personal page data.

The project is pre-release. Maintainers will confirm receipt and coordinate a fix and disclosure with the reporter.
